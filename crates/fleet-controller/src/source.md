# Fleet Controller Source Index

`fleet-controller` owns the HTTP/WebSocket controller interface and its adapters to application and storage contracts.
Production startup in `lib.rs` owns the Core data-directory lease from before storage/key access until runtime shutdown.

| Path | Kind | Responsibility | Boundary / Side effects |
| --- | --- | --- | --- |
| `admin_job_write.rs` | Interface | Adapts canonical protected Job ports to the selected Controller store and maps typed authorization/duplicate/backend errors safely. | Passes authenticated principals and prepared effects; owns no SQL or cached permission authority and never returns raw backend diagnostics. |
| `admin_crypto.rs` | Infrastructure | Owns crate-private fixed-profile password normalization/cryptography, purpose-bound human token generation/digests, independent human restore-epoch entropy and typed resource settings. | OS entropy and CPU/memory effects only; no store, actor authority, environment lookup or credential logging. Public password use goes through the bounded worker adapter. |
| `admin_crypto_tests.rs` | Test | Verifies synthetic password/token/restore-epoch cryptography, input bounds, normalization, entropy failure and redaction. | Real local KDF and OS entropy with fixture-only material; no listener, persisted credential or TLS trust changes. |
| `admin_http_tests.rs` | Test | Exercises human login, cookie/PAT and CSRF policy, setup, current role/revocation, quotas, audit rollback, startup cleanup and origin rejection through Controller HTTP/HTTPS. | Owned temporary SQLite and joined loopback servers; TLS trust is scoped to the test client and all identities are synthetic. No OS trust or user service changes. |
| `admin_http_contract_tests.rs` | Test | Verifies canonical-origin/cookie policy, header-only unique credentials and finite per-name failure/key admission. | Controlled monotonic time and synthetic request/store fixtures; no live network or external configuration. |
| `admin_http.rs` | Interface | Maps human login, session, logout and one-time setup to Application use cases, current-cookie/PAT authentication, canonical-origin/CSRF and bounded HTTP admission. | Same-origin HTTP and purpose-bound credentials only; owns no canonical SQL writes or CPU-worker lifecycle. |
| `admin_account_http.rs` | Interface | Maps owner-only account metadata, creation, metadata/role/disable changes and password reset to Application use cases, with strict scoped opaque positions. | Validates bounded known DTOs and same-request password proofs through shared CPU admission; returns setup/reset material once and clears a successfully revoked caller cookie. No SQL or canonical write authority. |
| `admin_account_http_tests.rs` | Test | Verifies owner mutations, role/disable/reset revocation, owner lockout prevention, clock-skew refusal, non-owner rejection and audit rollback through actual HTTP. | Synthetic identities in owned private SQLite and joined loopback servers; no user accounts, Agent sessions or services are changed. |

No SQL or canonical write authority. |
| `admin_business_http_tests.rs` | Test | Reproduces retained server-context business writes after actual account disable/logout and checks preservation of earlier committed Jobs. | Owned loopback people/SQLite and authenticated Agent WebSocket/restart fixtures; no host execution or user services. |
| `admin_self_http_tests.rs` | Test | Verifies all four roles' own password/PAT HTTP success, fixed expiry, input/scope refusal, selected/self revocation, quotas/cleanup, corrupt-row isolation, immutable audit actors and private audit rollback. | Synthetic people and tokens in owned SQLite/loopback fixtures; no user credentials, Agent sessions or external services. |
| `admin_metadata_http.rs` | Interface | Owns strict bounded human-metadata query parsing and version/subject/purpose-scoped opaque position encoding. | Pure HTTP codec only; callers validate typed ID positions and Application rechecks authority. No credential proof, persistence or canonical write authority. |
| `admin_identity_store.rs` | Infrastructure | Adapts identity reads, bounded account/PAT queries and atomic Application writes to the Controller-owned store and bounded bootstrap cleanup. | Holds the shared store mutex only for individual reads or transaction callbacks, never across password work or network await. |
| `admin_kdf_bench.rs` | Test | Provides explicitly requested fake-only Argon2id cost and parallelism measurements. | Ignored by default; bounded joined threads and public cost metadata only, no production credential, listener or runtime authentication path. |
| `admin_password_worker.rs` | Infrastructure | Owns bounded password CPU threads, admission/reply leases, request deadline/cancellation and the scoped Application password adapter. | No store or issuance authority; submission is bounded and shutdown closes cloned clients and joins all workers. |

| `controller_lease_tests.rs` | Test | Verifies the production bootstrap's data-directory lease before default/custom DB access and throughout healthy runtime, startup failure, and shutdown. | Owned private temporary fixtures and bounded loopback HTTP requests; no personal-auth acceptance, user service, or OS trust changes. |

| `catalog_execution.rs` | Interface | Authenticates strict catalog-reference Job creation and maps immutable Job provenance into protected detail responses. | Requires JobCreate/PolicyRead, calls Application preflight/required authority-aware composite creation and existing post-commit dispatch; no raw body/actor override, SQL or automatic POST retry. |
| `output_page.rs` | Interface | Maps authenticated output-page reads to the Application port, validates scoped opaque cursors and query budgets, and serializes precision-preserving fragment DTOs and typed errors. | Strict percent/base64url/JSON boundaries, purpose-separated scope hashing, no-store/2MiB responses; SQLite dispatch only, no SQL or execution authority. | `catalog_fetch.rs` | Infrastructure | Validates a public Git authority, pins each libgit2 HTTPS tunnel to policy-checked DNS addresses through a controller-local CONNECT proxy, resolves requested fetched origin branches without substituting HEAD, and decodes bounded immutable Git tree blobs into validated catalog fetch results while ignoring unrelated YAML and rejecting invalid declared Fleet documents, links, submodules, or oversized catalog documents. | Resolves and reads Git through libgit2; never accepts credentials or invokes a shell. The proxy rejects other CONNECT authorities and closes stalled tunnels at the hard deadline or cancellation. |
| `report_receipt.rs` | Interface | Signs v2 stored receipts from committed inbox effects or terminal-preserving G2/cancellation dispositions, persists or replays exact bytes through an Application port, and verifies stored bytes before returning them. | Called by authenticated lifecycle TaskAck/TaskStarted/TaskRejected, DriftEvidence, output, and supported final-result handlers, including artifact-bearing Runbook and DriftCheck finals; the helper itself owns no session authentication, network transport, or Agent cleanup. |
| `lib.rs` | Interface | Serves controller APIs with Domain administrator permission policy and authenticated v2 agent sessions, provides durable Controller namespace/epoch during authentication, commits SQLite lifecycle TaskAck acceptance, TaskStarted transitions, TaskRejected terminal transitions, terminal-preserving G2/cancellation lifecycle dispositions, output, DriftEvidence with correlated evidence/proposal effects, and supported Command/Runbook/DriftCheck final-result reports—including artifact metadata/body effects—and queues persisted signed receipts on the session writer, validates inbound drift correlation, renders remediation lifecycle from persisted assignment/evidence rows, rejects deprecated manual lifecycle mutations, joins persisted verification result/evidence for origin-only remediation resolution, delegates authorized human Job cancellation to Application before queue delivery, maps task lifecycle events and the required catalog creation bundle to application persistence ports, with catalog-reference HTTP creation and Job-detail provenance delegated to its interface module, and exposes authorized durable catalog reads and no-store source-scoped sync-operation status plus owner/admin source registration and bounded asynchronous sync-start requests; owns bounded catalog-sync, assignment-recovery, and pending-final-result recovery workers, performs pre-listener verification, remediation-resolution, G2 Assignment and pending-final effect/receipt recovery, and dispatches committed remediation verification Jobs. | Performs network, storage, signing, audit, and session-registry coordination through explicit controller dependencies; catalog fetch and pending-final recovery run in bounded blocking-store passes without holding store locks across session I/O. G2 and pending-final effect/receipt recovery use bounded passes before listener bind and lifecycle-owned periodic workers; SQLite is supported and Postgres report recovery remains unsupported. Live report effects are SQLite-only and fail closed on Postgres; persistent Command/no-artifact Runbook final reports require exact stored stdout/stderr prefixes and a strict count/truncation summary. Artifact-bearing Runbook reports validate included bodies and use a prepared SQLite final effect/receipt, but the Agent does not journal them and pre-inbox disconnect remains unrecoverable. |
